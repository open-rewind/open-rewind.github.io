# open-rewind.github.io

[倒带用户网站](https://open-rewind.github.io/) 的 GitHub Pages 发布仓库。页面在 [open-rewind/rewind 的 website 目录](https://github.com/open-rewind/rewind/tree/main/website)维护。

发布工作流每小时第 17 分检查一次源码。网站目录有新提交时，构建并发布静态页面。需要立即发布时，可在 [Publish website](https://github.com/open-rewind/open-rewind.github.io/actions/workflows/pages.yml) 页面选择 **Run workflow**。线上版本见 [website-revision.txt](https://open-rewind.github.io/website-revision.txt)。
